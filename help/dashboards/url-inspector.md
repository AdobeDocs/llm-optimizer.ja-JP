# URL インスペクタ

URL インスペクターは、AI 検索でドメイン上の特定のページがどのように実行されているかを分析するのに役立ちます。 表示、エージェンティックトラフィックおよびリファラルデータを URL レベルで組み合わせることで、引用される URL の詳細と、それらが応答に表示される頻度を把握できます。 **SR-NEEDS CDN?**

![URL インスペクター ](/help/dashboards/assets/url-insp.png)

## フィルター

ページの上部で、フィルターを適用してビューを絞り込むことができます。 選択するフィルターは、ダッシュボードに存在するセクション **すべて** に影響します。 次の項目をカスタマイズできます。

* **日付範囲** – 表示されたデータの時間枠を選択します。 例：過去 4 週間。 また、「カスタム週 **オプションを選択して期間をカスタマイズするオプションもあり** す。
* **カテゴリ** – 表示される結果をカテゴリでフィルタリングできます。
* **プラットフォーム** – 分析する AI エンジンを選択します。
* **チャネル** - チャネル間でフィルタリングします（獲得済み、競合他社、ソーシャルなど）。
* **地域** – 結果を地域でフィルタリングします。 すべての地域がローンチ時に利用できるわけではありません。
目的のフィルターを選択したら、「**フィルターを適用**」をクリックして、選択をダッシュボードに適用します。

## 概要指標

URL インスペクターには、AI 検索でページのパフォーマンスをすばやく評価できるように、いくつかの概要指標が用意されています。 次の指標が提供されます。

* **所有済み引用を含む一意のプロンプト** – 所有済み引用を含む一意の AI プロンプトの合計数。（**SR の詳細？ 所有されている引用と**
* **一意プロンプトの合計** – 一意の AI プロンプトの合計数。
* **一意の引用 URL** – 引用された一意に所有されている URL の数。
* **合計被引用回数** – 所有 URL が AI 生成の回答で引用された合計回数。
* **合計エージェンティックヒット数** - URL 上の AI エージェントからのヒットの合計数。
* **LLM からのリファラルヒット** - AI が生成した、URL に対する回答からダイレクトされたヒットの合計数。

各概要指標のトレンド指標は、前期と比較して、これらの値が時間の経過とともにどのように変化しているかを示します。

## 引用した URL

引用された URL の表示には、AI が生成した回答で引用されたブランドのすべての URL と、サポート指標が一覧表示されます。 また、データテーブルには、特定の URL にすばやくアクセスするための検索フィールドもあります。 次の指標が提供されます。

* **URL** – 分析された URL
* **引用回数** - URL が AI によって生成された回答で引用された回数。
* **以下で引用されたプロンプト** - URL を引用した一意の AI プロンプトの数。
* **カテゴリ** - URL に関連付けられた製品カテゴリまたはトピック。
* **地域** - URL が引用された地理的地域。
* **エージェンティックヒット数** - URL 上の AI エージェントからのヒットの合計数。
* **リファラルヒット数** - AI が生成した URL への回答からダイレクトされたヒットの数。

## 引用と競合する URL のトレンド

引用を競合するトレンド URL 表示では、ブランドに関連する回答で現在引用されている外部 URL がハイライト表示され、スペースで誰が引用に勝っているかを測定します。 データテーブルには、特定の URL にすばやくアクセスするための検索フィールドがあります。 また、「**書き出し**」オプションを使用してテーブル .csv をダウンロードし、インサイトをチームで共有したり、エグゼクティブレポートにテーブルを含めたりできます。

![ 引用文献の競合する URL のトレンド ](/help/dashboards/assets/trend-url.png)

次の指標が提供されます。

* **URL** – 分析された URL
* **コンテンツタイプ** - コンテンツのタイプ（所有、ソーシャル、獲得、競合他社）。
* **引用回数** - URL が AI によって生成された回答で引用された回数。
* **以下で引用されたプロンプト** - URL を引用した一意の AI プロンプトの数。
* **カテゴリ** - URL に関連付けられた製品カテゴリまたはトピック。
* **地域** - URL が引用された地理的地域。

各 URL には、マウスポインターを置くと **詳細** ボタンが表示されます。 ボタンをクリックすると、詳細を含む別のウィンドウが表示されます。
