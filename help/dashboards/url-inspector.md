# URL インスペクター

URL インスペクターは、AI 検索におけるドメイン上の特定のページのパフォーマンスを分析するのに役立ちます。 URL レベルでの可視性、エージェントトラフィック、リファラルデータを組み合わせて、どの URL が引用されているか、応答にどのくらいの頻度で表示されるかを詳細に表示します。 **URL インスペクター**&#x200B;に移動し、インサイトを表示するサイトを選択します。

![URL インスペクター](/help/dashboards/assets/url-insp.png)

![URL インスペクター - サイトセレクター（ブランド中心のエクスペリエンス）](/help/assets/brand-centric-experience/url-inspector-dashboard.png)

## フィルター

ページの上部でフィルターを適用して表示を絞り込むことができます。 選択するフィルターは、ダッシュボードに存在する&#x200B;**すべて**&#x200B;のセクションに影響を与えます。 次の項目をカスタマイズできます。

* **日付範囲** - 表示するデータの時間枠を選択します。 例：過去 4 週間。 また、「**カスタム週**」オプションを選択して期間をカスタマイズするオプションもあります。
* **カテゴリ** - 表示された結果をカテゴリでフィルタリングします。
* **プラットフォーム** - 分析する AI エンジンを選択します。
* **ページコンテンツタイプ** - コンテンツのタイプでフィルタリングします。
* **地域** - 結果を地域でフィルタリングします。 すべての地域がローンチ時に使用できるわけではありません。

目的のフィルターを選択したら、「**フィルターを適用**」をクリックして、選択をダッシュボードに適用します。

## 概要指標

URL インスペクターには、いくつかの概要指標が用意されているので、AI 検索でのページのパフォーマンスをすばやく評価できます。 次の指標が表示されます。

* **所有コンテンツの引用を含む一意のプロンプト数** - 所有コンテンツの引用を含む一意の AI プロンプトの合計数。
* **一意のプロンプトの合計数** - 一意の AI プロンプトの合計数。
* **引用された一意の URL 数** - 引用された一意の所有コンテンツの URL の数。
* **引用された合計回数** - AI 生成回答で所有コンテンツの URL が引用された合計回数。
* **エージェント型の合計ヒット数** - AI エージェントによる URL へのヒットの合計数。
* **LLM からのリファレルヒット数** - AI 生成回答から URL に向けられたヒットの合計数。

各概要指標のトレンドインジケーターは、これらの値が前の期間と比較してどのように変化しているかを示します。

## 引用された URL

引用された URL ビューには、AI 生成回答で引用されたブランドのすべての URL が、サポート指標と共に一覧表示されます。 両方のテーブルには、トピックにすばやくアクセスする検索フィールドがあり、「**列を設定**」ボタンをクリックすると、表示する指標をカスタマイズできます。 また、「**書き出し**」オプションを使用してテーブル .csv をダウンロードし、インサイトをチームと共有したり、テーブルをエグゼクティブレポートに含めたりすることができます。

![引用された URL](/help/dashboards/assets/cited-urls.png)

次の指標が表示されます。

* **URL** - 分析対象の URL。
* **引用回数** - AI 生成回答で URL が引用された回数。
* **引用されたプロンプト** - URL を引用した一意の AI プロンプトの数。
* **カテゴリ** - URL に関連付けられた製品カテゴリまたはトピック。
* **地域** - URL が引用された地理的地域。
* **エージェント型のヒット数** - AI エージェントによる URL へのヒットの合計数。
* **リファラルヒット数** - AI 生成回答から URL に向けられたヒットの数。

## 引用を競うトレンド URL

引用を競うトレンド URL ビューでは、ブランドに関連する回答で現在引用されている外部 URL がハイライト表示され、スペースで引用獲得をリードしている対象を測定します。 データテーブルには、特定の URL にすばやくアクセスする検索フィールドがあります。 また、「**書き出し**」オプションを使用してテーブル .csv をダウンロードし、インサイトをチームと共有したり、テーブルをエグゼクティブレポートに含めたりすることができます。

![引用を競うトレンド URL](/help/dashboards/assets/trend-url.png)

次の指標が表示されます。

* **URL** - 分析対象の URL
* **コンテンツタイプ** - コンテンツのタイプ（所有、ソーシャル、獲得、他社）。
* **引用回数** - AI 生成回答で URL が引用された回数。
* **引用されたプロンプト** - URL を引用した一意の AI プロンプトの数。
* **カテゴリ** - URL に関連付けられた製品カテゴリまたはトピック。
* **地域** - URL が引用された地理的地域。

### 詳細ウィンドウ

引用ビューとトレンドビューの両方で、URL の各行の末尾に「**詳細**」ボタンがあります。 ボタンをクリックすると、追加の詳細情報を含む別のウィンドウが表示されます。 詳細ウィンドウには、URL の引用頻度、<!--the sentiment of AI responses where it is mentioned,-->表示されるトピックとプロンプト、エージェントトラフィックとリファラルトラフィックのトレンド（所有コンテンツの URL の場合）が表示されます。

![詳細ウィンドウ](/help/dashboards/assets/details-url.png)
