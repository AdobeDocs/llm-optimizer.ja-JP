# 共同作業

Collaborationでは、組織のLLM Optimizer workspace にチームメンバーを招待できるので、全員が 1 か所からインサイトと分析にアクセスできます。 同僚を追加することで、マーケティングチーム、SEO チーム、PR チーム、技術チームがシームレスに連携してブランドの可視性を向上させ、結果を共有し、機会に合わせて調整されたアクションを実行できるようになります。

## チームメンバーの招待方法

チームメンバーを招待するには、「**メールアドレス**」フィールドにメンバーのメールアドレスを追加して、「招待を送信 **をクリック** します。 承認すると、組織のLLM Optimizer Workspace に参加します。
