# コラボレーション

コラボレーションにより、チームメンバーを組織の LLM Optimizer ワークスペースに招待して、すべてのメンバーが 1 か所でインサイトと分析にアクセスできるようになります。同僚を追加することで、マーケティング、SEO、PR、技術の各チームがシームレスに連携してブランドの可視性の向上に取り組み、結果を共有し、機会に応じて調整されたアクションを実行できるようになります。

## チームメンバーの招待方法

「**メールアドレス**」フィールドにチームメンバーのメールを追加し、「**招待状を送信**」をクリックすると、チームメンバーを招待できます。承諾した場合、組織の LLM Optimizer ワークスペースに参加します。
