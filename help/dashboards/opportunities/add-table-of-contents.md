# 目次の追加

>[!NOTE]
>
> **早期アクセス** - この機能は早期アクセスで利用できます。能力の成熟度が高まるにつれて、ワークフローの可用性、適格性、部分が変化する可能性があります。 アクセスについて質問がある場合は、アドビのアカウントチームにお問い合わせください。

「目次を追加」のオポチュニティでは、明確な&#x200B;**目次**&#x200B;と構造ガイドが不足している高トラフィックのページを特定するため、AI エージェントがページを解析し、ユーザークエリを適切なセクションにマッピングすることが難しくなります。 ページの主なセクションを反映した&#x200B;**アンカーでリンクされた見出し**&#x200B;を持つ構造化された目次が導入されます。 この構造により、AI エージェントは関連する記述をより確実に抽出し、関連付けて、引用できるようになります。

影響を受ける各 URL について、提案された目次エントリを確認し、[Optimize at Edge](/help/dashboards/optimize-at-edge/overview.md) を使用してデプロイすることで、エージェントトラフィックが、コンテンツ管理システム（CMS）の変更なしで、より明確なナビゲーションコンテキストを受

## 問題の解決方法

修正は、[Optimize at Edge](/help/dashboards/optimize-at-edge/overview.md) を使用して適用されます。この機能では、次のことを実行できます。

- AI エージェントに事前レンダリング済みのHTML スナップショットを提供します。
- ページに目次を追加します。
- CDN レイヤーで機能します（CMS は変更されません）。
- AI のみ：人間の訪問者や SEO ボットには影響しません
- 数分でデプロイされ、LLM Optimizer インターフェイスから&#x200B;**完全に元に戻す**&#x200B;ことができます。

## 仕組み

LLM Optimizer は、**目次**&#x200B;を追加することで、AI エージェントによる見出しやセクションのナビゲーションが改善される高トラフィックのページを特定します。各ページの提案は、そのページに既にある見出しを基に生成されるため、目次はページの構成を反映したものになります。

影響を受ける URL は、**現在の提案**&#x200B;タブの **URL と提案**&#x200B;テーブルに表示されます。

**現在の提案**&#x200B;では、各 URL について、次の操作を実行できます。

- **行を展開**&#x200B;して、提案された目次を検査します（ページ上の見出しから解析され、アンカーでリンクされたエントリとして表示されます）。
- 比較の前後に&#x200B;**プレビュー**&#x200B;します。
- LLM Optimizer 以外でオポチュニティに対応した場合は、**修正済みとしてマーク**&#x200B;します。
- 関連性の低い提案を&#x200B;**無視**&#x200B;します。

提案は、他の Optimize at Edge オポチュニティと同様、**現在の提案**、**修正された提案**、**無視された提案**&#x200B;に整理されます。

### 最適化のデプロイ

Edge での公開の準備が整ったら、デプロイする目次の提案を選択します。フッターは、選択された項目の数を要約し、通常は&#x200B;**修正済みとしてマーク**、**提案を無視**、**最適化をデプロイ**&#x200B;の各操作を実行できます。

「**最適化をデプロイ**」をクリックします。選択した URL と最適化の詳細が、**Edge にデプロイ**&#x200B;ダイアログに一覧表示されます。リストを確認し、「**デプロイ**」または「**キャンセル**」を選択します。

デプロイが正常に完了すると、**デプロイメント完了**&#x200B;に、本番環境に反映された最適化の件数が表示されます。ダイアログを閉じ、**修正された提案**&#x200B;を開いてステータスを確認します。

>[!NOTE]
>
>最適化をデプロイするには、Edge での最適化のオンボーディングプロセスを完了する必要があります。 まだオンボードしていない場合は、「**最適化をデプロイ**」をクリックすると、オンボーディングプロセスに移動します。 Edge での最適化の仕組み、サポートされている CDNプロバイダー、オンボーディングプロセスについて詳しくは、[Edge での最適化](/help/dashboards/optimize-at-edge/overview.md)ページを参照してください。

### 修正された提案とライブ表示

**修正された提案**&#x200B;で、デプロイされた URL は、ステータス列に&#x200B;**最適化済み**&#x200B;と表示されます。 デプロイされた目次を確認するには、行を展開し、利用可能な場所で分析に&#x200B;**詳細**&#x200B;を使用するか、「**ライブ表示**」をクリックして、検証用に提供された&#x200B;**現在のページコンテンツ**&#x200B;の読み取り専用ビューを開きます（挿入された&#x200B;**目次**&#x200B;を含む）。

エッジの変更を一括で元に戻す必要がある場合は、チェックボックスを使用して最適化された行を選択し、ヘッダーに&#x200B;**ロールバック**&#x200B;を使用します。

## ロールバック

デプロイされた最適化は、必要に応じてロールバックできます。**修正された提案**&#x200B;ビューで、元に戻す最適化された行を選択し、ヘッダーの「**ロールバック**」をクリックします。

**ロールバック**&#x200B;ダイアログには、ロールバックされる提案が一覧表示され、デプロイされた最適化が元に戻されることを示す短い警告が表示されます。リストを確認し、「**ロールバック**」または「**キャンセル**」をクリックします。

操作が完了すると、**正常にロールバックされました**&#x200B;の概要が表示されます。ダッシュボードに戻るには、この概要を閉じます。
