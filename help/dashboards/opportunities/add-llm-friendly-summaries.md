# LLM に対応した概要を追加

「LLM に対応した概要を追加」オポチュニティでは、簡潔で構造化された概要がなく、AI エージェントがページ上の主要な情報をすばやく把握することが難しい高トラフィックのページを特定します。既存のページコンテンツに基づいて、明確な概要と重要なポイントが導入されます。これにより、エージェントは重要なブランドメッセージをより効率的に解釈して把握でき、AI の応答にコンテンツが正確に含まれる可能性が高まります。

影響を受ける URL ごとに、AI が生成した提案を確認し、[Optimize at Edge](/help/dashboards/optimize-at-edge/overview.md) を使用してデプロイすることで、Content Management System （CMS）の変更を必要とせずに、エージェントトラフィックがより明確でスキャン可能なコンテキストを得ることができます。

## 問題の解決方法

修正を適用する際には、[Optimize at Edge](/help/dashboards/optimize-at-edge/overview.md) を使用して、以下のことを行います。

- AI エージェントに事前レンダリング済みのHTML スナップショットを提供します。
- 取得した HTML の要約や重要なポイントでページをエンリッチします。
- CDN レイヤーで機能します（CMS は変更されません）。
- AI のみ：人間の訪問者や SEO ボットには影響しません
- 数分でデプロイされ、LLM Optimizer インターフェイスから&#x200B;**完全に元に戻すことができます**。

## 仕組み

LLM Optimizer は、ページレベルまたはセクションレベルの&#x200B;**概要**&#x200B;および&#x200B;**重要なポイント**&#x200B;が AI の理解に役立つ高トラフィックのページを特定します。 影響を受ける URL は、**現在の提案**&#x200B;タブの **URL と候補**&#x200B;テーブルに表示されます。このタブでは、行を展開して各レコメンデーションを調べることができます。

![現在の提案の候補を含む URL。ページとセクションの概要の候補を含む行が拡張されました](/help/dashboards/opportunities/assets/add-llm-friendly-summaries-expand.png)

候補&#x200B;**テーブルを含む** URLには、エージェントの検出に役立つ概要が表示されます。 候補は、**現在の提案**、**修正された提案**、**無視された提案**&#x200B;の 3 つのビューに整理されます。 各 URL について、次の操作を実行できます。

- **行を展開**&#x200B;して、分析と提案された概要テキスト（重要なポイントが含まれている場合はその内容も）を表示します。
- エージェントトラフィックの前後の比較を&#x200B;**プレビュー**&#x200B;します。
- LLM Optimizer 以外でオポチュニティに対応した場合は、**修正済みとしてマーク**&#x200B;します。
- 関連性の低い提案を&#x200B;**無視**&#x200B;します。

展開された各エントリには、ページレベルおよびセクションレベルの概要手順、**AIが生成した**&#x200B;コピー、編集コントロール、ライブページに関連付けられたコンテキストが表示されます。

**アクション**&#x200B;列の&#x200B;**プレビュー**&#x200B;をクリックして、最適化プレビューを開きます。 エージェントトラフィックのページの現在の見た目と、最適化後の見た目（例えば、挿入された&#x200B;**概要**&#x200B;や&#x200B;**重要なポイント**&#x200B;のコンテンツを提案されたプレースメントに合わせて）を比較します。 デプロイする前にいつでもプレビューを開いたり閉じたりできます。

公開する準備ができたら、チェックボックスを使用して概要と重要なポイントの行の項目を選択します。 フッターには、選択された数が表示され、**修正済みとしてマーク**、**提案を無視**、**最適化をデプロイ**&#x200B;の各操作を実行できます。

![現在の提案では、概要行の項目が選択され、フッターに最適化をデプロイが表示される](/help/dashboards/opportunities/assets/add-llm-friendly-summaries-select-url.png)

### 最適化のデプロイ

エッジで公開する準備ができたら、**最適化をデプロイ**&#x200B;をクリックします。 選択した URL と最適化の詳細が、**Edge にデプロイ**&#x200B;ダイアログに一覧表示されます。 リストを確認し、**デプロイ**&#x200B;または&#x200B;**キャンセル**&#x200B;を選択します。

![Edge にデプロイダイアログ](/help/dashboards/opportunities/assets/add-llm-friendly-summaries-deploy-dialog.png)

デプロイが正常に完了すると、**デプロイメント完了**&#x200B;に、本番環境に反映された最適化の件数が表示されます。また、AI エージェントが更新内容をインデックス化するまでに時間がかかる場合があることも通知されます。ダイアログを閉じ、**修正された提案**&#x200B;を開いてステータスを確認します。

![デプロイメントが完了しました](/help/dashboards/opportunities/assets/add-llm-friendly-summaries-deploy-confirm.png)

>[!NOTE]
>
>最適化をデプロイするには、Edge での最適化のオンボーディングプロセスを完了する必要があります。 まだオンボードしていない場合は、「**最適化をデプロイ**」をクリックすると、オンボーディングプロセスに移動します。 Edge での最適化の仕組み、サポートされている CDNプロバイダー、オンボーディングプロセスについて詳しくは、[Edge での最適化](/help/dashboards/optimize-at-edge/overview.md)ページを参照してください。

### 修正された提案とライブ表示

**修正された提案**&#x200B;で、デプロイされた URL は、ステータス列に&#x200B;**最適化済み**&#x200B;と表示されます。 行を展開して、デプロイされた概要コピーと手順を確認します。

![最適化されたステータス、展開された概要の拡張、ライブ表示、および詳細が表示された「修正された提案」タブ](/help/dashboards/opportunities/assets/add-llm-friendly-summaries-fixed.png)

行の「**ライブ表示**」をクリックしすると、検証用に提供された&#x200B;**現在のページコンテンツ**&#x200B;が読み取り専用で表示されます。適用されている場合は、挿入された&#x200B;**概要**&#x200B;ブロックと&#x200B;**重要なポイント**&#x200B;ブロックも含まれます。分析に&#x200B;**詳細**&#x200B;を使用します。 エッジの変更を一括で元に戻す必要がある場合は、チェックボックスを使用して最適化された行を選択し、ヘッダーに&#x200B;**ロールバック**&#x200B;を使用します。

![ロールバック前の一括選択のチェックボックス付きの修正された提案](/help/dashboards/opportunities/assets/add-llm-friendly-summaries-select-in-fixed.png)

## ロールバック

必要に応じて、展開された最適化はいつでもロールバックできます。**修正された提案**&#x200B;ビューで、元に戻す最適化された行を選択し、ヘッダーの「**ロールバック**」をクリックします。

**ロールバック**&#x200B;ダイアログには、ロールバックされる提案が一覧表示され、展開された最適化が元に戻されることを示す短い警告が表示されます。 リストを確認し、**ロールバック**&#x200B;または&#x200B;**キャンセル**&#x200B;をクリックします。

![ロールバックダイアログに、元に戻す候補が一覧表示されます](/help/dashboards/opportunities/assets/add-llm-friendly-summaries-rollback-dialog.png)

操作が完了すると、**正常にロールバックされました**&#x200B;の概要が表示されます。ダッシュボードに戻るには、この概要を閉じます。

![ロールバック完了 – ロールバックが完了しました](/help/dashboards/opportunities/assets/add-llm-friendly-summaries-rollback-confirm.png)
