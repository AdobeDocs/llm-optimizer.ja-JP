# マルチメディアトランスクリプト要約の追加

>[!NOTE]
>
> **早期アクセス** - マルチメディアトランスクリプトの概要の追加は、早期アクセスで利用できます。能力の成熟度が高まるにつれて、ワークフローの可用性、適格性、部分が変化する可能性があります。 アクセスについて質問がある場合は、アドビのアカウントチームにお問い合わせください。

「マルチメディアトランスクリプトの概要を追加」オポチュニティは、AI エージェントが読み取ることができるトランスクリプトや短いテキストの概要がなくても、重要な情報がビデオやその他のメディアに存在するページを特定します。メディアと周囲のページのコンテキストに基づいて&#x200B;**AI 生成のトランスクリプトの概要**&#x200B;を導入します。AI エージェントがマルチメディアコンテンツを理解できるようにすることで、そうでなければ見落とされてしまう重要なブランド情報を回復できます。

影響を受ける各 URL について、提案された&#x200B;**コンテンツパッチ**、**実装**&#x200B;の詳細（例：ターゲット CSS セレクターと操作）および&#x200B;**論理的根拠**&#x200B;を確認し、[Edge での最適化](/help/dashboards/optimize-at-edge/overview.md)を使用してデプロイすることで、エージェントトラフィックが、コンテンツ管理システム（CMS）の変更を必要とせずに強化された HTML を受け取れるようになります。

## 問題の解決方法

修正は、[Edge での最適化](/help/dashboards/optimize-at-edge/overview.md)を使用して適用されます。この機能では、次のことを実行できます。

- AI エージェントに事前レンダリング済みのHTML スナップショットを提供します。
- 取得した HTML のトランスクリプト要約テキストでページをエンリッチします（例：関連するインラインビデオの近く）。
- CDN レイヤーで機能します（CMS は変更されません）。
- AI のみ：人間の訪問者や SEO ボットには影響しません
- 数分でデプロイされ、LLM Optimizer インターフェイスから&#x200B;**完全に元に戻す**&#x200B;ことができます。

## 仕組み

LLM Optimizer は、設定とページ構造に基づいて、埋め込みメディアに機械が読み取れるテキストが欠落している高トラフィックのページをフラグ付けします。影響を受ける URL は、「**現在の提案**」タブの **URL と候補**&#x200B;テーブルに表示されます。このタブでは、行を展開して、各&#x200B;**コンテンツパッチ**、その適用方法、その推奨の理由を調べることができます。

各ページには、次の要素が含まれます。

**マルチメディア概要** - ビデオコンテンツから派生した構造化された概要。
**プレビュー** - ページ比較の前後。

![現在の提案の候補を含む URL。コンテンツパッチ、実装の詳細、論理的根拠を含む行が拡張されました](/help/dashboards/opportunities/assets/add-multimedia-transcript-summaries-expand.png)

**提案を含む URL** のテーブルには、エージェント型の検出に役立つトランスクリプトまたは概要テキストページが一覧表示されます。候補は、**現在の提案**、**修正された提案**、**無視された提案**&#x200B;の 3 つのビューに整理されます。各 URL について、次の操作を実行できます。

- **行を展開**&#x200B;して、**コンテンツパッチ**&#x200B;テキスト、**実装**&#x200B;の詳細（予定されている DOM 操作と CSS セレクターを含む）、および変更の&#x200B;**論理的根拠**&#x200B;を表示します。
- エージェントトラフィックの前後の比較を&#x200B;**プレビュー**&#x200B;します。
- LLM Optimizer 以外でオポチュニティに対応した場合は、**修正済みとしてマーク**&#x200B;します。
- 関連性の低い提案を&#x200B;**無視**&#x200B;します。

サポートされている場合は、行からパッチテキストを編集できます（鉛筆コントロール）。次に、行のチェックボックスを使用して、デプロイする内容を選択します。フッターには、選択された数が表示され、**修正済みとしてマーク**、**提案を無視**、**最適化をデプロイ**&#x200B;の各操作を実行できます。

### 最適化のデプロイ

エッジで公開する準備ができたら、「**最適化をデプロイ**」をクリックします。**Edge にデプロイ**&#x200B;ダイアログには、プッシュする URL、セレクター、操作が一覧表示されます。リストを確認し、「**デプロイ**」または「**キャンセル**」を選択します。

![マルチメディアトランスクリプト要約コンテンツパッチの Edge へのデプロイダイアログ](/help/dashboards/opportunities/assets/add-multimedia-transcript-summaries-deploy-dialog.png)

デプロイが正常に完了すると、**デプロイメント完了**&#x200B;に、本番環境に反映された最適化の件数が表示されます。ダイアログを閉じ、**修正された提案**&#x200B;を開いてステータスを確認します。

![デプロイメントが完了しました](/help/dashboards/opportunities/assets/add-multimedia-transcript-summaries-deploy-confirm.png)

>[!NOTE]
>
> 最適化をデプロイするには、Edge での最適化のオンボーディングプロセスを完了する必要があります。 まだオンボードしていない場合は、「**最適化をデプロイ**」をクリックすると、オンボーディングプロセスに移動します。 Edge での最適化の仕組み、サポートされている CDNプロバイダー、オンボーディングプロセスについて詳しくは、[Edge での最適化](/help/dashboards/optimize-at-edge/overview.md)ページを参照してください。

### 修正された提案とライブ表示

**修正された提案**&#x200B;で、デプロイされた URL は、ステータス列に&#x200B;**最適化済み**&#x200B;と表示されます。 行を展開して、ライブの&#x200B;**コンテンツパッチ**、**実装**&#x200B;の詳細、**論理的根拠**&#x200B;を確認します。さらに、**詳細**&#x200B;を分析に使用するか、**ライブ表示**&#x200B;を使用して、エージェントトラフィックの受信を確認できます。

![最適化済みステータス、拡張されたコンテンツパッチ、ロールバックを含む修正された候補](/help/dashboards/opportunities/assets/add-multimedia-transcript-summaries-fixed.png)

一括でロールバックするには、チェックボックスを使用して最適化された行を選択し、ヘッダーに&#x200B;**ロールバック**&#x200B;を使用します。

![ロールバック実行前に行を選択した状態の修正された提案](/help/dashboards/opportunities/assets/add-multimedia-transcript-summaries-select-in-fixed.png)

## ロールバック

デプロイされた最適化は、必要に応じてロールバックできます。**修正された提案**&#x200B;で元に戻す行を選択し、**ロールバック**&#x200B;をクリックします。

**ロールバック**&#x200B;ダイアログには、ロールバックされる提案の一覧が表示され、デプロイ済みの最適化がエージェントトラフィック向けのライブパスから削除されることが警告されます。確認後、**ロールバック**&#x200B;または&#x200B;**キャンセル**&#x200B;をクリックします。

![元に戻す提案の一覧が表示されたロールバックダイアログ](/help/dashboards/opportunities/assets/add-multimedia-transcript-summaries-rollback-dialog.png)

操作が完了すると、**正常にロールバックされました**&#x200B;の概要が表示されます。ダッシュボードに戻るには、この概要を閉じます。

![ロールバック完了 – ロールバックが完了しました](/help/dashboards/opportunities/assets/add-multimedia-transcript-summaries-rollback-confirm.png)
