# 複雑なコンテンツの簡素化

「複雑なコンテンツを簡略化」オポチュニティでは、AI エージェントが重要な情報を解釈しにくくする、密度が高いまたは複雑な文章を含む高トラフィックページを特定します。この機会では、元の意味を維持したまま、既存の文章をより明確で読み取りやすい表現に改善します。これにより、AI エージェントは重要な情報をより正確に解析、要約、および抽出できるようになります。

影響を受ける各 URL について、**改善されたテキスト**&#x200B;の提案を確認し、**プレビュー**&#x200B;で比較した後、[Edgeでの最適化](/help/dashboards/optimize-at-edge/overview.md)を使用してデプロイできます。これにより、コンテンツ管理システム（CMS）を変更することなく、エージェントトラフィックに対してより明確な HTML を提供できます。

## 問題の解決方法

修正は、[Edge での最適化](/help/dashboards/optimize-at-edge/overview.md)を使用して適用されます。この機能では、次のことを実行できます。

- AI エージェントに事前レンダリング済みのHTML スナップショットを提供します。
- AI エージェントに表示されるページを更新し、複雑な文章をライブページの内容に沿った&#x200B;**改善されたテキスト**&#x200B;に置き換えるか、補足します。
- CDN レイヤーで機能します（CMS は変更されません）。
- AI のみ：人間の訪問者や SEO ボットには影響しません
- 数分でデプロイされ、LLM Optimizer インターフェイスから&#x200B;**完全に元に戻す**&#x200B;ことができます。

## 仕組み

LLM Optimizer は、エージェントトラフィックの多いページのうち、コンテンツの可読性が基準を下回るページを特定し、文章の改善案を提案します。各ページでは、次のことができます。

**改善されたテキスト**：ページ上の既存のコンテンツに基づいて簡潔化した文章。
**プレビュー**：エージェントトラフィック向けの変更前後を比較できるプレビュー。

影響を受けるURLは、「**現在の提案**」タブの&#x200B;**候補を含む URL** テーブルに表示されます。このタブでは、各行を展開すると、それぞれの推奨内容を確認できます。

![現在の提案の「候補を含む URL」テーブル（展開された行に改善されたテキストとプレビュー が表示された状態）](/help/dashboards/opportunities/assets/simplify-complex-content-expand.png)

**候補を含む URL** テーブルには、簡潔化したコンテンツによってエージェントの理解が向上するページが一覧表示されます。候補は、**現在の提案**、**修正された提案**、**無視された提案**&#x200B;の 3 つのビューに整理されます。各 URL について、次の操作を実行できます。

- **行を展開**&#x200B;して、そのページの **改善されたテキスト**&#x200B;の提案を表示します。
- **プレビュー**&#x200B;で、エージェントトラフィック向けの変更前後の比較を確認します。
- LLM Optimizer 外部で改善のオポチュニティに対応した場合は、**修正済みとしてマーク**&#x200B;します。
- 関連性の低い提案を&#x200B;**無視**&#x200B;します。

**ビュー**&#x200B;には、**現在の提案**、**修正された提案**（デプロイ済みの場合はステータスが&#x200B;**最適化済み**）、および&#x200B;**無視された提案**&#x200B;が含まれます。**ライブ表示**&#x200B;を&#x200B;**修正された提案**&#x200B;で使用してライブデプロイを確認でき、いつでもロールバックできます。

チェックボックスを使用して、適用する&#x200B;**改善されたテキスト**&#x200B;が含まれる URL または項目を選択し、**オポチュニティプラン**&#x200B;ヘッダーの&#x200B;**修正済みとしてマーク**、**提案を無視**、または&#x200B;**最適化をデプロイ**&#x200B;を使用します。デモ UI には、選択数と、リストに関連するアクションも表示されます。

![オポチュニティプラン、現在の提案、展開された行、およびプランヘッダーの最適化をデプロイ](/help/dashboards/opportunities/assets/simplify-complex-content-select.png)

### 最適化のデプロイ

エッジで公開する準備ができたら、「**最適化をデプロイ**」をクリックします。選択した URL と最適化の詳細が、**Edge でのデプロイ**&#x200B;ダイアログに一覧表示されます。リストを確認し、「**デプロイ**」または「**キャンセル**」を選択します。

![Edge にデプロイダイアログ](/help/dashboards/opportunities/assets/simplify-complex-content-deploy-dialog.png)

デプロイが正常に完了すると、**デプロイメント完了**&#x200B;に、本番環境に反映された最適化の件数が表示されます。また、AI エージェントが更新内容をインデックス化するまでに時間がかかる場合があることも通知されます。ダイアログを閉じ、**修正された提案**&#x200B;を開いてステータスを確認します。

![デプロイ完了の確認](/help/dashboards/opportunities/assets/simplify-complex-content-deploy-confirm.png)

>[!NOTE]
>
>最適化をデプロイするには、Edge での最適化のオンボーディングプロセスを完了する必要があります。 まだオンボードしていない場合は、「**最適化をデプロイ**」をクリックすると、オンボーディングプロセスに移動します。 Edge での最適化の仕組み、サポートされている CDNプロバイダー、オンボーディングプロセスについて詳しくは、[Edge での最適化](/help/dashboards/optimize-at-edge/overview.md)ページを参照してください。

### 修正された提案とライブ表示

**修正された提案**&#x200B;で、デプロイされた URL は、ステータス列に&#x200B;**最適化済み**&#x200B;と表示されます。行を展開して、デプロイ済みの&#x200B;**改善されたテキスト**&#x200B;と手順を確認します。

![最適化されたステータス、展開表示された簡潔化済みテキスト、ライブ表示、および詳細が表示された「修正済み提案」タブ](/help/dashboards/opportunities/assets/simplify-complex-content-fixed.png)

行の「**ライブ表示**」をクリックすると、検証用に提供される&#x200B;**現在のページコンテンツ**&#x200B;の読み取り専用ビューが開きます（適用済みの簡潔化された文章を含む）。分析に&#x200B;**詳細**&#x200B;を使用します。

![ライブ表示 — エージェント向けの簡潔化されたテキストを含む現在のページコンテンツ](/help/dashboards/opportunities/assets/simplify-complex-content-view-live.png)

エッジの変更を一括で元に戻す必要がある場合は、チェックボックスを使用して最適化された行を選択し、ヘッダーに&#x200B;**ロールバック**&#x200B;を使用します。

![デプロイ済みの行を展開した状態、最適化済みステータス、およびヘッダーのロールバックが表示された修正された提案](/help/dashboards/opportunities/assets/simplify-complex-content-rollback.png)

## ロールバック

必要に応じて、展開された最適化はいつでもロールバックできます。**修正された提案**&#x200B;ビューで、元に戻す最適化された行を選択し、ヘッダーの「**ロールバック**」をクリックします。

**ロールバック**&#x200B;ダイアログには、ロールバックされる提案が一覧表示され、展開された最適化が元に戻されることを示す短い警告が表示されます。リストを確認し、「**ロールバック**」または「**キャンセル**」をクリックします。

![ロールバックダイアログに、元に戻す候補が一覧表示されます](/help/dashboards/opportunities/assets/simplify-complex-content-rollback-dialog.png)

操作が完了すると、**正常にロールバックされました**&#x200B;の概要が表示されます。ダッシュボードに戻るには、この概要を閉じます。

![ロールバック完了 – ロールバックが完了しました](/help/dashboards/opportunities/assets/simplify-complex-content-rollback-confirm.png)
