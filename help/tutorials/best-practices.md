# ベストプラクティス

[ ドラフト ]

LLM 最適化は、生成エンジン最適化（GEO）、回答エンジン最適化（AEO）、AI 最適化（AIO）とも呼ばれ、ChatGPT、Perplexity、Copilot、Gemini、その他の LLM 駆動のアシスタント間で、AI によって生成された回答でブランドとコンテンツを可視化、信頼、検索できるようにする方法です。

従来の SEO がページワンランキングの獲得に役立った場合、LLM 最適化は AI の引用と回答エンジン内の可視性の獲得に役立ちます。 Adobe LLM Optimizerを使用すると、回答エンジン内でのブランドの可視性を測定および向上できます。

この記事では、Adobe LLM Optimizerを使用した AI 駆動型検索環境での可視性と影響力の測定および強化に関するベストプラクティスについて説明します。

## LLM ブランド表示のロック解除

大規模言語モデル（LLM）最適化は、AI 駆動環境でブランドを検出し、参照する方法を変革しています。 AdobeのLLM Optimizerは、ブランドの認知度を高める構造化されたアプローチを提供します。

LLM の可視性を向上させるには、次の手順に従います。

1. **分析：** 複数の LLM をまたいだ主要な顧客プロンプトで、ブランドがどのように表示されるかを確認します。
2. **プラン：** フォーカスされたキャンペーンに対して類似の目的を持つプロンプトの Target クラスター。
3. **Act:** 変更を実装し、LLM の可視性の推移を経時的に監視します。
4. **適応：** オプティマイザーの実用的なインサイトに基づいて戦略を調整します。

これらの手順を理解し活用することで、AI が情報検出の中心となるため、ブランドの関連性を維持するのに役立ちます。

## LLM と SEO の主な違い

優れた LLM 戦略は、優れた SEO 戦略に基づいて構築されます。 SEO 戦略は、あらゆる LLM 最適化の基盤となります。 現在、SEO トラフィックは、依然としてほとんどの web サイトへのトラフィックの最大のドライバーであり、ブランドの可視化戦略にとって非常に重要です。

LLM の最適化は、いくつかの重要な違いがあるため、従来の SEO とは異なることを理解することが重要です。

* LLM はインデックスではなくトークンを使用します。結果は、インデックスのないトレーニング済みデータから生成されますが、LLM は検索エンジンを使用して、取得拡張生成（RAG）による迅速な回答を強化します。
* RAG を介したリアルタイム情報：検索エンジンはリアルタイムデータを使用しますが、RAG を使用すると、LLM は最新の情報を取得でき、幻覚を減らすことができます。
* クライアントサイドの JS レンダリングの制限：LLM は現在、クライアントサイドのJavaScriptを処理せず、表示されるコンテンツに影響します。

これらの基本的な違いがあるため、LLM 戦略では次の点を考慮する必要があります。

* ブランドの言及は LLM へのリンクよりも重要：LLM は、バックリンクよりもコンテンツの関連性とブランドプレゼンスを優先します。 SEO とは異なり、LLM は権限を判断するためにリンクを使用しません。
* コンテンツの鮮度が重要：LLM は最近更新されたコンテンツを優先します。 （検索エンジンでは、時間依存のクエリに対してこれを優先しますが、他の値により大きく依存します）。
* メンションや引用の形で獲得した（サードパーティ）は非常に重要です。

## 戦略的なキャンペーン計画

成功する LLM 最適化キャンペーンを構築するには、次の操作を行います。

価値の高いトピックを特定：迅速な意図をビジネス目標および顧客ニーズに合わせます。
競合他社の言及を見つける：競合他社が引用されるプロンプトに焦点を当て、ブランドを取り入れる機会を示します。
インテント別にプロンプトをグループ化：トピックと検索フィールドを使用して、類似したユーザー目標をクラスター化し、表示のベンチマークに使用します。
現実的なブランドインクルージョンを評価する：EEEAT （経験、専門知識、権威、信頼性）や YMYL （あなたのお金またはあなたの人生）などの基準を考慮して、ブランドが信頼に足るかどうかを評価します。

この戦略的アプローチにより、LLM の可視性におけるターゲット設定されたデータ駆動型の改善が保証されます。


## アクションにつながる最適化手順

LLM Optimizerでは、「機会 [ ダッシュボードにおける最適化の機会を提案し ](/help/dashboards/opportunities.md) す。

以下に、LLM でのブランドの認知度を高めるために考慮すべき実用的なアクションを示します。

* ウィキペディアのページを更新：会社および引用ページが最新で関連性が高いことを確認します。
* LLM アクセスを有効にする：robots.txt および CDN 設定を監視して、AI ボットがブロックされないようにします。
* コンテンツを改善：ページコンテンツの 10～15% を更新、参照を追加、ヘッダー（H1、H2、H3）で構造を改善します。
* FAQ を追加：プロンプト分析に基づいて関連する FAQ を統合し、ユーザーからの問い合わせに対応します。
* Reddit/Quora でブランドメンションを増やす：LLM が引用を提供するユーザー生成コンテンツプラットフォームに貢献します。 トリガーを設定する際は、この方法に注意する必要があります

これらの手順を一貫して実行すると、AI 駆動型の検索結果でのブランドのプレゼンスを大幅に高めることができます。



## LLM の可視性とは

LLM の可視性は、ChatGPT やその他の AI モデルなどのツールで生成された回答に、ブランドがどの程度の頻度で表示されるかに関するものです。

## LLM の進捗状況の測定方法

Web サイトの可視性をベンチマークして作業の成果を確認するには、次の主要指標を追跡します。

* **メンション：** ブランドが応答でメンションされた回数。
* **引用：** LLM がコンテンツまたはソースを使用して質問に回答する頻度。
* **センチメント：** ブランドのメンションがポジティブ、ニュートラル、ネガティブのどれであるかを示します。
* **位置：** ブランドが応答で言及される場所（最初、中間、最後など）。

これらの要因はすべて **可視性** スコアに結合され、LLM 応答でのブランドのプレゼンスの強さを示します。

## 表示変更の追跡方法

LLM でのブランドの可視性を監視する方法を次に示します。

1. 現在の表示を確認
   * Adobe LLM Optimizerは、ブランドが言及および引用される頻度と、LLM の応答におけるセンチメントを示します。 ブランドプレゼンスダッシュボードを参照してください。
   * ブランドが言及されている場所と欠落している場所を確認するプロンプト（質問）を表示します。
   * 自社の可視性を競合他社と比較して、自社の積み重ね具合を確認します。
   * Reddit、Quora、Wikipedia などのユーザー生成プラットフォームでは、情報を見つけるために LLM によって引用されることが多いので、どのように表示されているかを確認します。
   * エージェンティックトラフィックにどのように表示されているかを確認します。 エージェンティックトラフィックは多くの場合、ホームページに移動しません – それはエージェントが訪問するページを見る価値があります。
   * LLM からコンテンツが表示され、アクセス可能であることを確認します。 Chrome プラグインを使用して、AI エージェントが表示できる内容を確認できます。

1. 戦略の計画
   * ユーザーの質問に基づいて、類似のプロンプトをグループ化します。
   * 顧客にとって最も重要なプロンプトに焦点を当てます。
   * ブランドが特定のプロンプトでメンションされる可能性が高いかどうかを確認します。
   * コンテンツが、自分の専門知識、信頼性、権威（EEEAT）を示していることを確認します。

1. コンテンツの改善
   * LLM Optimizerのオポチュニティを使用して、サイトを特定し、特に推奨される即時の変更を行います。 [ 商談 ](/help/dashboards/opportunities.md) を参照（その後、結果を測定）。 機会の節を定期的に確認し、提供された推奨事項に対して行動を起こします。
   * Web サイトやその他のコンテンツを更新して、ターゲットにするプロンプトとの関連性を高めます。
   * ユーザーがよく尋ねる質問に回答する FAQ をページに追加します。
   * LLM がコンテンツを簡単に検索および読み取れるようにしてください。 ブロックされたページや web サイトのコードに関する問題などの問題を修正します。
   * Wikipedia や Reddit などのプラットフォームへの投稿が公平で、非営利であり、価値を付加することを保証します。
   * Adobe LLM Optimizerを使用して、時間の経過に伴う表示の変化を追跡します。
   * 競合他社が頻繁にメンションされていることに気付いた場合は、一歩先を行くために戦略を調整します。
   * ユーザーが検索および尋ねている内容に合わせてコンテンツを更新し続けます。
