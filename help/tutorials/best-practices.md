# ベストプラクティス

## LLM ブランド表示のロック解除

大規模言語モデル（LLM）最適化は、AI 駆動環境でブランドを検出し、参照する方法を変革しています。 AdobeのLLM Optimizerは、ブランドの認知度を高める構造化されたアプローチを提供します。

次の手順に従うと、LLM の可視性を向上できます。

1. 分析：LLM 全体の主要な顧客プロンプトでブランドがどのように表示されるかを確認します。
2. 計画：焦点を絞ったキャンペーンに対して同様の目的でプロンプトのクラスターをターゲットにします。
3. アクション：変更を実装し、LLM の表示の推移を経時的に監視します。
4. 適応：オプティマイザーからの実用的なインサイトに基づいて戦略を絞り込みます。
5. これらの手順を理解し活用することで、AI が情報検出の中心となるため、ブランドの関連性を維持するのに役立ちます。

## LLM と SEO の主な違い

LLM の最適化は、従来の SEO とは基本的に異なります。

* LLM は、インデックスではなくトークンを使用します。結果は、インデックスのない、トレーニング済みデータから生成されます。
* ブランドの言及はリンクよりも重要：LLM はバックリンクよりもコンテンツの関連性とブランドプレゼンスを優先します。
* RAG を介したリアルタイム情報：Retrieval-Augmented Generation を使用すると、LLM は最新の情報を取得でき、幻覚を減らすことができます。
* クライアントサイドの JS レンダリングの制限：LLM は現在、クライアントサイドのJavaScriptを処理せず、表示されるコンテンツに影響します。
* リンク権限アトリビューションなし：SEO とは異なり、LLM は権限を決定するためにリンクを使用しません。
* これらの違いを認識することは、LLM を効果的に最適化するために重要です。


## アクションにつながる最適化手順

LLM Optimizerは、商談ダッシュボードで最適化の商談を提案します。

次に、LLM でのブランドの認知度を高めるための実用的なアクションを示します。

* ウィキペディアのページを更新：会社および引用ページが最新で関連性が高いことを確認します。
* LLM アクセスを有効にする：robots.txt および CDN 設定を監視して、AI ボットがブロックされないようにします。
* コンテンツを改善：ページコンテンツの 10～15% を更新、参照を追加、ヘッダー（H1、H2、H3）で構造を改善します。
* FAQ を追加：プロンプト分析に基づいて関連する FAQ を統合し、ユーザーからの問い合わせに対応します。
* Reddit/Quora でブランドメンションを増やす：LLM が引用を提供するユーザー生成コンテンツプラットフォームに貢献します。

これらの手順を一貫して実行すると、AI 駆動型の検索結果でのブランドのプレゼンスを大幅に高めることができます。


## 戦略的なキャンペーン計画

成功する LLM 最適化キャンペーンを構築するには、次の操作を行います。

価値の高いトピックを特定：迅速な意図をビジネス目標および顧客ニーズに合わせます。
競合他社の言及を見つける：競合他社が引用されるプロンプトに焦点を当て、ブランドを取り入れる機会を示します。
インテント別にプロンプトをグループ化：トピックと検索フィールドを使用して、類似したユーザー目標をクラスター化し、表示のベンチマークに使用します。
現実的なブランドインクルージョンを評価する：EEEAT （経験、専門知識、権威、信頼性）や YMYL （あなたのお金またはあなたの人生）などの基準を考慮して、ブランドが信頼に足るかどうかを評価します。

この戦略的アプローチにより、LLM の可視性におけるターゲット設定されたデータ駆動型の改善が保証されます。


このレポートは、大規模言語モデル（LLM）におけるブランドの可視性が時間の経過と共にどのように変化するかを把握するのに役立つように設計されています。 LLM で生成された応答でのブランドのプレゼンスを追跡、改善および測定する手順を説明します。

LLM の可視性とは
LLM の可視性は、ChatGPT やその他の AI モデルなどのツールで生成された回答に、ブランドがどの程度の頻度で表示されるかに関するものです。 状況は次によって異なります。

メンション：ブランドが応答でメンションされた回数。
引用：LLM がコンテンツまたはソースを使用して質問に回答する頻度。
センチメント：ブランドのメンションがポジティブ、ニュートラル、ネガティブのどれであるかを示します。
位置：ブランドが応答で言及される場所（例：最初、中央、最後）。

これらの要因はすべて可視化スコアに統合され、ブランドのプレゼンスが LLM 応答でどの程度強力であるかがわかります。

## ジェネレーティブエンジン最適化（GEO）/回答エンジン最適化（AEO）に関する PR およびコミュニケーションマネージャーガイド

PR とコミュニケーションマネージャーの目標は、メディアの報道をコントロールし、ジャーナリストの発言だけでなく、AI システムの発言を管理することです。 誰かが AI ボットにブランド、製品、CEO について尋ねると、モデルはプレスリリース、ウィキペディア、レビュー、サードパーティのメンションなど、web 全体からのデータを統合することです。

この新しい AI エコシステムでブランドのストーリーを形作り、保護することに焦点を当てています。

地域ツールに必要なもの

* AI ブランド監視：主要な AI システムによるブランド、エグゼクティブ、製品の記述方法を可視化する必要があります。
* センチメントとトーンのトラッキング：AI の応答が、望ましい声と感情的なトーンを反映しているかどうかを評価します。
* Sourceの影響マッピング：AI 出力の形成に最も影響を与えるメディア、レビューサイト、サードパーティページを把握する必要があります。
* 物語の精度スコアリング：事実の精度を検証し、古くなったデータや誤ったデータを検出します。
* 危機検出アラート：AI モデルが誤った表現を広めたときに直ちに通知が必要です。
* コンテンツ検証ツール：適切な構造化された権威のあるデータを（スキーマ、ウィキペディア、ナレッジグラフを介して）エコシステムにフィードする。
