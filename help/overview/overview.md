# LLM Optimizer の概要

## Adobe LLM Optimizer とは

Adobe LLM Optimizer は、生成エンジン最適化（回答エンジン最適化とも呼ばれる）用の生成 AI ファーストアプリケーションで、AI 駆動型検索環境でのブランドの可視性、精度、影響力を高めるように設計されています。 AI 生成回答でブランドプレゼンスに関するインサイトを用意し、規範的なコンテンツのレコメンデーションを提供し、最適化の修正を自動化します。

## LLM Optimizer の機能とは

Adobe LLM Optimizer には、生成エンジン最適化用に設計されたツールスイートが用意されています。

* **ブランドの可視性を測定**：ベンチマーク用のクリアな可視性スコアを使用して、AI を活用した検索結果にブランドが表示されるタイミング、位置、頻度を追跡します。
* **その他をベンチマーク**：生成エンジンでブランドのシェアオブボイスとプレゼンスを競合他社を含むその他と比較します。
* **実用的な機会を検出**：言及と引用を増やすには、コンテンツと技術的な改善点（FAQ、要約、スキーマ、クロール可能性など）を特定します。
* **トラフィックの影響を追跡**：所有コンテンツのプロパティに対するエージェント（AI アシスタント）トラフィックとリファラルトラフィックの両方を監視し、可視性をエンゲージメントにリンクします。
* **チームコラボレーションを有効にする**：ダッシュボードを共有し、所有者を割り当て、マーケティング、SEO、コミュニケーションチームをまたいで目標を調整します。

## LLM 最適化がブランドにとって重要な理由

LLM 最適化は、ますます重要になっています。

* AI 生成回答は、消費者の検出を再形成しています。
* LLM Optimizer では、これらの環境でブランドの可視性、正確性、影響力を確保します。
* AI の可視性を、エンゲージメントや売上高など、実際のビジネス成果に結び付けます。
* ゼロクリックジャーニーの世界では、このツールは競争力を維持するのに不可欠です。

## Adobe LLM Optimizer を使用する必要があるユーザー

生成エンジン最適化は、本質的に部門横断的です。 LLM Optimizer は、以下に示す様々なペルソナ向けに、このレンズを使用して設計されています。

* **マーケティングマネージャー**&#x200B;は、AI 検索でブランドの可視性とキャンペーンの効果を測定します。
* **SEO アナリスト**&#x200B;は、ブランド言及、引用、その他のインサイトを追跡して、コンテンツ戦略を策定します。
* **PR およびコミュニケーションマネージャー**&#x200B;は、サードパーティプラットフォームによる LLM でのブランドイメージを追跡し、誤情報に対処し、センチメントを管理し、ブランドの信頼を保護します。

## Adobe LLM Optimizer でできること

Adobe LLM Optimizer を使用すると、次の操作を実行できます。

**ブランドの可視性を測定** - AI を活用した検索結果にブランドが言及されるタイミング、位置、頻度を追跡します。 推測に頼らずに、時間の経過と共にベンチマークできるクリアな可視性スコアを使用します。 詳しくは、[ブランドプレゼンスダッシュボード](/help/dashboards/brand-presence.md)を参照してください。
**その他をベンチマーク** - 生成エンジンでブランドが競合他社を含むその他のブランドと比較してどうなっているかを確認します。 シェアオブボイスのギャップを特定し、競争上のメリットを明らかにします。 詳しくは、[ブランドプレゼンスダッシュボード](/help/dashboards/brand-presence.md)を参照してください。
**実用的な機会を検出** - 言及と引用を直接増やすコンテンツの機会（例：FAQ、要約、スキーマ）と技術的な機会（クロール可能性、インデックス作成の問題）を特定します。 詳しくは、[機会ダッシュボード](/help/dashboards/opportunities-overview.md)を参照してください。
**AI からトラフィックの影響を追跡** - 所有コンテンツのプロパティに対するエージェントトラフィック（AI アシスタントから）とリファラルトラフィック（引用からのユーザークリック）を監視します。 GEO の可視性を実際のエンゲージメントに結び付けます。 詳しくは、[エージェントトラフィックダッシュボード](/help/dashboards/agentic-traffic.md)および[リファラルトラフィックダッシュボード](/help/dashboards/referral-traffic.md)を参照してください。
**チームコラボレーションを有効にする** - ダッシュボードを共有し、プロンプトやカテゴリの所有者を割り当て、マーケティング、検索エンジン最適化（SEO）、コミュニケーション機能をまたいで可視性の目標が追跡されるようにします。 詳しくは、[コラボレーションダッシュボード](/help/dashboards/collaboration.md)を参照してください。
